# Interfaz de Asistencia TMT

Para una tarea concreta de interfaz, lee AGENTS.md y DESIGN.md en la raíz del proyecto. Aplica las reglas de diseño a React Native y limita el trabajo a la pantalla o componente solicitado.

- Para diseñar una pantalla nueva o definir su dirección visual, lee [frontend-design](../frontend-design/SKILL.md).
- Para auditar o pulir una interfaz existente, lee [impeccable](../impeccable/SKILL.md) y elige el flujo pertinente.
- Para consultar patrones de interacción, accesibilidad o React Native, lee [ui-ux-pro-max](../ui-ux-pro-max/SKILL.md).

Combina las guías cuando la tarea cubra varios de esos objetivos. Si el usuario solo abre la skill, pregunta qué pantalla o componente quiere trabajar y qué resultado busca.
